# Portfólio | Douglas Carvalho

**De projetos elétricos a linhas de código.**

Portfólio pessoal desenvolvido para o Challenge 3 (Presença Digital) da Residência Full Stack 5.0. O site apresenta minha transição da engenharia elétrica para o desenvolvimento fullstack, reunindo formação, stack, projetos e experiência profissional.

🔗 **Acesse:** https://dcgs77.github.io/portfolio-douglas-carvalho/

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, Flexbox, media queries)
- JavaScript puro (menu responsivo)
- Figma (prototipação)
- Git e GitHub Pages (versionamento e hospedagem)

## Seções

- **Hero:** apresentação e chamada para os projetos
- **Sobre:** trajetória, motivação e números
- **Stack:** tecnologias que utilizo
- **Projetos:** Detector de Golpes em Java com IA (Google Gemini)
- **Experiência:** atuação profissional
- **Contato:** e-mail, LinkedIn e GitHub
